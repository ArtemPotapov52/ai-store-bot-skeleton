Остаток и автовыдача

Каждая сохранённая единица склада выдаётся одному покупателю и затем списывается. Поле ниже — единый текст результата, без отдельных полей для логина и пароля.

  • один аккаунт или один ключ — одна единица склада;
  • для нескольких аккаунтов нажмите внизу «Добавить много аккаунтов» и загрузите список одним полем;
  • логин, пароль и инструкцию для одного аккаунта вставляйте в большое текстовое поле несколькими строками.

Переключатель «Выдавать без ограничения» оставляйте выключенным для аккаунтов и ключей. Он нужен для одного текста или ссылки, которые можно отправлять каждому покупателю.
